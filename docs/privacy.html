Privacy Policy

Last updated: 2026-08-28

This application is a personal, single-owner automation tool used to publish video content to a small set of YouTube channels owned by the developer, and to read basic performance analytics for those same channels. It is not a public-facing product and does not have external end users.

What data is accessed

Using Google's YouTube Data API and YouTube Analytics API, this application accesses only the YouTube channels the developer has explicitly authorized via Google OAuth, to:

  • Upload video content to those channels
  • Read basic channel/video metadata needed to manage uploads
  • Read aggregate performance analytics (views, watch time) for those channels

What is not done

This application does not collect, store, or share data about any third party or end user. It does not access any Google account or YouTube channel other than the developer's own. No data is sold or shared with any other party.

Data retention

OAuth credentials are stored only as encrypted CI secrets under the developer's control, used solely to refresh access for automated publishing.

Contact

Questions about this policy can be sent to the repository owner via the GitHub repository.
